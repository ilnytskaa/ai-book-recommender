# 📚 LitRecommend - Інтелектуальна система тематичного підбору літератури

Сучасна веб-система для персоналізованого підбору книг з використанням штучного інтелекту ChatGPT.

## 🌟 Особливості

- **Інтелектуальний пошук**: Опишіть свої уподобання природною мовою
- **Персоналізовані рекомендації**: ШІ аналізує ваш запит та підбирає ідеальні книги
- **Сучасний UI**: Красивий та зручний інтерфейс з адаптивним дизайном
- **Швидкість**: Оптимізована продуктивність завдяки Next.js
- **Багатомовність**: Підтримка української мови

## 🚀 Технології

- **Frontend**: Next.js 15, React 19, TypeScript
- **Styling**: Tailwind CSS
- **AI Integration**: OpenAI GPT-3.5-turbo
- **Icons**: Lucide React
- **HTTP Client**: Axios

## 📋 Передумови

- Node.js 18+ 
- npm або yarn
- OpenAI API ключ

## 🛠️ Встановлення

1. **Клонуйте репозиторій**
   ```bash
   git clone <repository-url>
   cd literature-recommendation-system
   ```

2. **Встановіть залежності**
   ```bash
   npm install
   ```

3. **Налаштуйте змінні середовища**
   
   Створіть файл `.env.local` в корені проекту:
   ```env
   OPENAI_API_KEY=your_openai_api_key_here
   NEXTAUTH_URL=http://localhost:3000
   NEXTAUTH_SECRET=your_nextauth_secret_here
   ```

4. **Запустіть проект**
   ```bash
   npm run dev
   ```

5. **Відкрийте браузер**
   
   Перейдіть на `http://localhost:3000`

## 🔑 Отримання OpenAI API ключа

1. Зареєструйтесь на [OpenAI Platform](https://platform.openai.com/)
2. Перейдіть в розділ API Keys
3. Створіть новий ключ
4. Скопіюйте ключ в файл `.env.local`

## 🎯 Використання

1. **Введіть запит**: Опишіть, яку книгу ви шукаєте
   - "Хочу щось романтичне про подорожі"
   - "Детектив з неочікуваним фіналом"
   - "Наукова фантастика про ШІ"

2. **Отримайте рекомендації**: Система проаналізує ваш запит та запропонує персоналізовані варіанти

3. **Вивчіть результати**: Кожна рекомендація містить:
   - Назву та автора
   - Опис книги
   - Жанр та рік видання
   - Рейтинг
   - Пояснення, чому ця книга підходить саме вам

## 🔧 Налаштування

### Зміна моделі OpenAI

В файлі `src/app/api/recommendations/route.ts` можна змінити модель:

```typescript
const completion = await openai.chat.completions.create({
  model: "gpt-4", // або "gpt-3.5-turbo"
  // ...
});
```

### Налаштування промпта

Відредагуйте змінну `prompt` в тому ж файлі для зміни поведінки ШІ.

## 📊 API Endpoints

### POST /api/recommendations

Отримання рекомендацій книг.

**Request Body:**
```json
{
  "query": "Опис бажаної книги"
}
```

**Response:**
```json
{
  "recommendations": [
    {
      "title": "Назва книги",
      "author": "Автор",
      "description": "Опис",
      "genre": "Жанр",
      "year": 2023,
      "rating": 4.5,
      "reason": "Чому підходить"
    }
  ],
  "query": "Оригінальний запит"
}
```
