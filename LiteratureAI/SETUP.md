# 🔧 Налаштування OpenAI API

## Швидкий старт

Зараз система працює з демонстраційними рекомендаціями. Щоб увімкнути повну функціональність з ChatGPT, виконайте наступні кроки:

## 1. Отримання OpenAI API ключа

### Крок 1: Реєстрація
1. Перейдіть на [OpenAI Platform](https://platform.openai.com/)
2. Натисніть "Sign up" або "Log in"
3. Створіть акаунт або увійдіть в існуючий

### Крок 2: Створення API ключа
1. Після входу перейдіть в розділ [API Keys](https://platform.openai.com/api-keys)
2. Натисніть "Create new secret key"
3. Дайте ключу назву (наприклад: "LitRecommend")
4. Скопіюйте згенерований ключ (він починається з `sk-`)

⚠️ **Важливо**: Збережіть ключ в безпечному місці. Ви не зможете його побачити знову!

## 2. Налаштування проекту

### Крок 1: Створення файлу змінних середовища
1. В корені проекту `literature-recommendation-system` створіть файл `.env.local`
2. Додайте наступний вміст:

```env
# OpenAI API Key
OPENAI_API_KEY=sk-your_actual_api_key_here

# Next.js налаштування
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=your_random_secret_string_here
```

### Крок 2: Заміна ключа
Замініть `sk-your_actual_api_key_here` на ваш справжній API ключ з OpenAI.

### Крок 3: Перезапуск сервера
```bash
# Зупиніть сервер (Ctrl+C) та запустіть знову
npm run dev
```

## 3. Перевірка роботи

1. Відкрийте http://localhost:3000
2. Введіть будь-який запит в форму пошуку
3. Якщо все налаштовано правильно, ви отримаєте персоналізовані рекомендації від ChatGPT
4. Якщо з'явиться повідомлення про демонстраційні рекомендації - перевірте правильність API ключа

## 4. Вартість використання

- OpenAI API платний сервіс
- GPT-3.5-turbo коштує приблизно $0.002 за 1000 токенів
- Один запит рекомендацій коштує приблизно $0.01-0.02
- Нові користувачі отримують $5 безкоштовного кредиту

## 5. Налаштування лімітів (рекомендовано)

1. В [OpenAI Dashboard](https://platform.openai.com/usage) встановіть місячний ліміт витрат
2. Рекомендований ліміт для тестування: $10-20/місяць

## 6. Альтернативні моделі

В файлі `src/app/api/recommendations/route.ts` можна змінити модель:

```typescript
// Для кращої якості (дорожче)
model: "gpt-4"

// Для економії (швидше, дешевше)
model: "gpt-3.5-turbo"
```

## 7. Усунення проблем

### Помилка 401 (Unauthorized)
- Перевірте правильність API ключа
- Переконайтесь, що ключ активний в OpenAI Dashboard

### Помилка 429 (Rate Limit)
- Ви перевищили ліміт запитів
- Зачекайте кілька хвилин або збільште ліміт в налаштуваннях

### Помилка 500 (Internal Server Error)
- Перевірте, чи правильно налаштований файл `.env.local`
- Перезапустіть сервер розробки

## 8. Безпека

- **Ніколи** не додавайте `.env.local` в git
- Не діліться API ключем з іншими
- Використовуйте різні ключі для розробки та продакшену

## 9. Продакшен

Для деплою на Vercel:
1. Додайте змінні середовища в налаштуваннях проекту Vercel
2. Встановіть `OPENAI_API_KEY` в Environment Variables
